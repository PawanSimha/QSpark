Architecture

How QSpark works under the hood

A clean MVC architecture powered by Spring Boot - from browser to database and back.

BrowserThymeleaf HTML + Vanilla JS
Spring SecurityBCrypt auth, CSRF, secure headers
ControllersLogin, Parking, QR - MVC handlers
Service LayerBusiness logic, validation, rules
RepositorySpring Data JPA + Hibernate ORM
DatabaseMySQL (prod) / H2 (dev)

Frontend Rendering

  • Thymeleaf generates full HTML server-side
  • Vanilla JS for progressive enhancements
  • Dark mode, toasts, table sorting included

Spring Security

  • BCrypt password hashing at login
  • CSRF tokens on all POST forms
  • Secure headers prevent XSS attacks

MVC Controllers

  • LoginController handles auth flow
  • ParkingController manages full CRUD
  • QRCodeController generates and scans

Business Logic

  • Slot availability validation on booking
  • Duplicate vehicle detection enforced
  • Regex pattern validation on numbers

Data Persistence

  • Spring Data JPA with Hibernate ORM
  • Three entities: admin, slot, registration
  • Auto DDL update for schema management

Dual Database Support

  • MySQL 8.0 for production deployment
  • H2 in-memory for dev and testing
  • Profile-based switching via Spring config

FAQ

Frequently asked questions

What is QSpark?

QSpark is a smart parking management system that helps parking lot administrators manage vehicle parking digitally. It tracks who parks where, for how long, and lets you find vehicles instantly using QR codes. It is free and open-source.

Who is QSpark for?

QSpark is built for parking lot administrators and staff who need to manage parking operations efficiently. It is ideal for commercial parking facilities, apartment complexes, office buildings, and multi-level parking garages.

How does QR scanning help?

Instead of typing vehicle numbers and owner details every time a regular visitor arrives, you generate a QR code once, print it, and scan it on re-entry. The system auto-fills all the details so you just pick a slot and confirm - saving time and avoiding typos.

Is QSpark really free?

Yes. QSpark is free software licensed under GNU GPLv3. You can download, use, modify, and share it. There are no hidden charges, subscriptions, or paid tiers.

Do I need internet to use it?

No. QSpark runs entirely on your local network. Once installed on a server, you access it through a web browser from any device on the same network. The only feature that needs internet is camera-based QR scanning, which can be downloaded and hosted locally if needed.

What do I need to run it?

A computer with Java 17 installed. For testing, the built-in H2 database requires no setup. For production, you need a MySQL server. That is it - no other dependencies.

How do I get started with QSpark?

Clone the repository from GitHub, ensure Java 17 is installed, and run .\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=h2" to start with the built-in H2 database. The admin credentials are pre-configured in the seed data.
