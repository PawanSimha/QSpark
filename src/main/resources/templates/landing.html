Architecture

How It Works Under the Hood

A clean 3-tier architecture connecting the browser through Spring Boot to MySQL (or H2), with client-side JavaScript for a smooth live experience.

BROWSER (Client)
HTTP Request / Thymeleaf HTML
SPRING BOOT - localhost:8080
Controller Layer LoginController • ParkingController
Repository Layer AdminRepository • ParkingRepository (Spring Data JPA)
Entity Layer Admin (@Entity) • ParkingSlot (@Entity)
JDBC • JPA / Hibernate ORM
DATABASE (MySQL / H2)

Request Lifecycle

Every action in the dashboard follows this 5-step path through the stack.

1
Request Browser sends an HTTP request (GET /dashboard or POST /save) to Spring Boot on port 8080.
2
Controller Spring MVC maps the URL to the correct method via @GetMapping/@PostMapping. Session guard checks authentication using session.getAttribute("admin"). Business logic executes — save booking, mark vehicle as left (/left/{id}), update, or delete.
3
Repository Spring Data JPA auto-generates SQL from method names like findBySlotNumber(). No manual SQL needed.
4
Entity JPA maps Java objects (@Entity) to MySQL rows. Hibernate generates INSERT, SELECT, UPDATE, DELETE statements.
5
Response & Client-Side JS Thymeleaf processes templates with model data and returns fully-formed HTML. On the browser, JavaScript handles live clock, auto-format vehicle numbers, cascading dropdowns, instant search filtering, and column sorting — all without page reloads.
